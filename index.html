    Cover settings
    
    
    
      
    
        
        
        
    Covers are looked up on TheMovieDB first, which gives the most reliable posters. A built-in key is used by default, so this field can stay empty. To use your own free key instead, paste the v3 API key or the long v4 read access token (starts with “eyJ”); it stays in this browser only and is never included in backups. Clear the field to go back to the built-in key. This product uses the TMDB API but is not endorsed or certified by TMDB.

    An older version of the app picked covers by itself, and some were the wrong film. This looks each one up again and compares. A cover that matches is marked as verified; any other gets a “Check cover” tag on its card. Nothing is replaced unless you choose it (Keep, or Wrong cover?). Sort by “Covers to review first” to see them together. It makes many web requests, so it only runs when you start it.
